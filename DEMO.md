# Tomo: 2-minute demo

Before you start: `npm start`, Team tab open. If Discord or CREAO credits fail, set `CREAO_MODE=mock` in `.env` and restart; every step below still works, labeled **mock**, with fake votes.

## 0:00 – 0:30 Agent team running (Track 2)
1. **Team** tab → **Run team**.
2. Watch the chain: Mail Scanner → Deadline & Task Analyst → Planner → Digest Writer, each going Working → Done, with the handoff on each arrow ("handed over 5 important emails", "8 ranked tasks").
3. Point at the morning brief on the same tab.

## 0:30 – 0:55 Handoffs and approvals (Track 3)
1. **Inbox** tab: study blocks and deadlines wait here; nothing is on the calendar yet.
2. Approve a study block. Open **Week**: it appears striped as "Study: …"; dashed blocks are still suggestions (click one: Approve right in the card).

## 0:55 – 1:15 Reality check
1. **Focus** tab: start the timer on the top task.
2. Back on **Team**: "your estimates usually run X% short". The Planner gets this history and lengthens future blocks.

## 1:15 – 1:35 Track 3 segment: the group hears about it (20 seconds)
1. A club meeting posted in Discord ("Club meeting Thursday 5-6pm in S34") was read by the **Analyst**: it sits in **Inbox → Events ✨ from Discord**. Approve it.
2. Open it on the calendar → **Ask the group**. The preview shows "Who's in? Club meeting · Thu … · S34" and **Posting to #channel** → **Send**.
3. **Check RSVPs**: "I'm in 3 · Maybe 1 · Can't make it 0". The winner is clear; it's already on the calendar.

## 1:35 – 2:00 Shared task and digest
1. Tick a task marked **shared**: preview "Betsy finished: …" → Send.
2. **Team → Post digest**: only approved events and shared work ("Club meeting · Thu …", "Group slides: not done"), again behind a preview. The Digest Writer's brief stays in the app.
3. Close: remove an agent's key and Run team → that part of the app goes empty (see README, "What happens without the agents").
